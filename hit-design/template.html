05 / IN THE PRODUCTION PATH

계획에서 렌더링까지 연결

  1. 소재·원고한 대상의 볼 이유와 마지막 답. 기존 원문·인용 검토를 통과합니다.
  2. 장면 계획현재 문장에서 장면 역할과 강조 구절을 고르고, 대상이 잘 보이는 구도를 지정합니다.
  3. 화면 생성기존 장수 산정 규칙·모델로 슬라이드를 생성합니다. 원고와 맞지 않는 대상·시대는 검수합니다.
  4. 최종 화면제목 띠300px, 자막의 핵심어 한 곳, 실제 장면·자막·그림 해시가 담긴 디자인 계획을 기록합니다.

새 확산/비전 호출, 상주 모델, 강제 작업 종료를 추가하지 않았습니다. 비교 이미지는 기존 자체 자산의 실제 Template 합성입니다. 새 완성 영상의 전체 청취·내용 승인과 공개 후48시간/7일 조회·유지율은 별도 관측입니다.10만 조회 달성이나 상승 폭은 아직 입증되지 않았습니다.
